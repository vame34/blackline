## ✨ Что такое BlackLine?

BlackLine помогает оценить торговую идею как систему: исторические входы и выходы, комиссии, размер позиций и портфельную просадку. В том же терминале можно просматривать текущие сигналы. Smart Volume включена как сменный адаптер стратегии.

| | Возможность | Что можно посмотреть |
| :-- | :-- | :-- |
| 📊 | **Бэктест** | Портфель или выбранные монеты; периоды до двух лет при наличии истории. |
| 🔎 | **История сделок** | Вход, выход, направление, комиссии, доходность и расчётный баланс. |
| 🛡️ | **Риск-менеджмент** | Ограничения риска сделки и портфеля, лестница риска, контроль просадки. |
| 🧩 | **Адаптеры стратегий** | Добавление адаптера, регистрация и выбор в интерфейсе. |
| 📡 | **Живая лента** | Обновления в браузере через WebSocket; REST и SSE API. |
| 🌍 | **Интерфейс RU / EN** | Тексты терминала и документация проекта на двух языках. |

Это исследовательское ПО. Аудит текущей стратегии **не установил положительное ожидание**. Прошлые результаты не гарантируют будущую прибыль. BlackLine не выставляет ордера на бирже.

## 🚀 Быстрый запуск

### Требования

- **PHP 8.2+** с BCMath, Intl, PDO MySQL, PCNTL и Zip; Composer.
- **Node.js 20.19+ или 22.12+**; npm.
- **MariaDB/MySQL** и **Redis**; для них можно использовать Docker Compose.

### 1. Установка и настройка

В каталоге проекта:

```bash
cp .env.example .env
composer install
php artisan key:generate
npm ci
```

Укажите свои локальные `DB_*`, `DB_ROOT_PASSWORD` и `REDIS_*` в `.env`. В примере MariaDB работает на `127.0.0.1:33316`, Redis — на `127.0.0.1:6379`. Перед использованием замените пароли-заглушки базы.

### 2. Запуск базы и Redis

```bash
docker compose up -d mariadb redis
```

Если эти сервисы уже работают локально, используйте их и поправьте `.env`.

### 3. Инициализация и запуск

```bash
php artisan migrate --seed
npm run build
php artisan serve --host=127.0.0.1 --port=8080
```

Откройте **[localhost:8080](http://localhost:8080)**.

Сидер создаёт эти **тестовые аккаунты только для разработки** в `local` / `testing`:

| Аккаунт | Email | Пароль |
| :-- | :-- | :-- |
| Пользователь | `user@example.com` | `password` |
| Администратор | `admin@example.com` | `password` |

Смените тестовые пароли для своей установки. В других окружениях эти аккаунты не создаются; обычная регистрация доступна на `/register`.

<details>
<summary><strong>🐳 Запуск всего стека в Docker</strong></summary>

После создания `.env` и установки PHP/frontend-зависимостей:

```bash
docker compose up -d --build
docker compose exec php php artisan key:generate
docker compose exec php php artisan migrate --seed
```

Compose запускает Nginx, PHP, базу, Redis, обработчики очередей, планировщик и Reverb. PHP-контейнеры используют внутренние адреса `mariadb:3306` и `redis:6379`. Опубликованные порты привязаны к `127.0.0.1`.

Сервис `node` запускает Vite в режиме разработки. Для собранного frontend выполните `npm run build` и остановите сервис `node`. Используйте один HTTP-сервер на порту 8080: Docker или нативный Artisan.

## 🔑 API-ключи: что действительно нужно

**Для текущего приложения API-ключи Binance не нужны.** Провайдер свечей читает публичные spot-данные через `GET /api/v3/klines`. Импорт истории и обновление рыночных данных используют этот endpoint без подписи запросов и доступа к биржевому аккаунту. Нужны интернет и доступность провайдера; ограничения частоты запросов публичного API сохраняются.

| Ключ или токен | Откуда взять | Для чего нужен |
| :-- | :-- | :-- |
| API key / secret Binance | Свой аккаунт Binance, если в будущем вы реализуете авторизованный провайдер данных. | Текущий публичный провайдер свечей их не использует. |
| API-токен BlackLine | Создайте свой токен в `/api/docs`. | Запросы к REST / SSE API этой установки. |
| Reverb app ID / key / secret | Сгенерируйте свои значения и сохраните в `.env` своей установки. | Обновления через WebSocket. |

API-токен BlackLine и ключи Reverb — **учётные данные приложения, а не Binance**. Приватные ключи и секреты храните в своём `.env`, исключённом из Git. Само добавление ключа Binance в `.env` не подключает приватные биржевые endpoint.

## 🕯️ Загрузка истории

Архивы свечей и пользовательская база **не входят** в репозиторий. Начните с BTC и короткого периода перед большим импортом.

```bash
php artisan signals:backfill-volume --help
php artisan signals:import-volume-market --help
```

Пример: просчитать календарный год BTC вместе с выходами. Время задаётся в миллисекундах, UTC:

```bash
php artisan signals:backfill-volume \
  --symbol=BTCUSDT \
  --strategy=smart_volume_v1 \
  --interval=15m \
  --context-interval=1h \
  --start-time=1735689600000 \
  --end-time=1767225600000 \
  --full-range \
  --simulate-exits \
  --dry-run
```

В примере период **01.01.2025 → 01.01.2026**. Уберите `--dry-run`, чтобы сохранить результат. Выберите свои даты и монеты, затем откройте `/performance/terminal`. Большой импорт зависит от доступности провайдера и может занять время.

## 📡 Обновления в реальном времени

Для нативного локального запуска выполните в отдельных терминалах:

```bash
php artisan horizon
php artisan schedule:work
```

В приватном `.env` установите `BROADCAST_CONNECTION=reverb` и заполните `REVERB_APP_ID`, `REVERB_APP_KEY`, `REVERB_APP_SECRET`, `REVERB_HOST=127.0.0.1`, `REVERB_PORT=8081`, `REVERB_SCHEME=http`. Затем:

```bash
php artisan config:clear
php artisan reverb:start --host=127.0.0.1 --port=8081
```

Терминал получает настройки WebSocket при открытии страницы. Сигналы обновляются внутри браузера. Авторизация сохраняет восстановление пароля и подтверждение email; локальный почтовый драйвер по умолчанию пишет эти письма в лог.

## 🧩 Подключение и переключение стратегий

1. Реализуйте `App\Contracts\Trading\StrategyAdapter`.
2. Верните DTO `StrategySignal` внутри `StrategyResult`.
3. Зарегистрируйте адаптер в `config/strategies.php`.
4. Выберите его в ленте/бэктесте или передайте `--strategy=your_strategy_v1`.

```bash
php artisan signals:run-strategy --strategy=smart_volume_v1 --symbol=BTCUSDT --dry-run
```

`STRATEGY_ACTIVE` выбирает генератор по умолчанию. Общие комиссии, параметры исполнения и ограничения портфеля находятся в `config/trading.php`. Запросы и кеш разделяют данные разных стратегий.

## 🧮 Как читать результаты

Smart Volume использует только известные на момент входа данные, включая завершённые контекстные свечи. Стоп проверяется по **high/low**, тейк — по **закрытию**. При одновременном касании стопа и тейка по умолчанию выбирается консервативный исход — стоп. Учтены комиссии входа/выхода и проскальзывание.

Цель по просадке — **40%**. При **20%** риск снижается, при **32%** новые входы прекращаются. Эти правила не гарантируют максимальную рыночную просадку.

Кривая капитала учитывает реализованный результат закрытых сделок. Открытый PnL, funding, заём и ликвидации моделируются не полностью. Spot-свечи не доказывают исполнимость фьючерсных short-сделок. Перед оценкой результатов прочитайте [аудит стратегии](docs/research/DRAWDOWN_40_2026-10-08.md).

## 🤝 Участие в разработке

Делайте небольшие изменения и добавляйте проверки существенного поведения. Обновляйте RU и EN вместе. Для новых стратегий нужны тесты независимости от будущих данных и совпадения live/backtest; подключение алгоритма само по себе не доказывает прибыльность.

Храните `.env`, ключи, базы, свечи, логи и приватные резервные копии вне Git.
